# multi-agent-vedanti

Dev container workspace. The project directory on this Mac is bind-mounted into the container.

| Location | Path |
| --- | --- |
| Mac | `/Users/VedantiV.Patil/Multi_Agent_Vedanti` |
| Container | `/workspaces/multi-agent-vedanti` |

Open this folder in Cursor, then run **Dev Containers: Reopen in Container** from the Command Palette. Docker Desktop must be running. The first open downloads the image and installs Git and the GitHub CLI inside the container.

Git remote: `https://github.com/VedantiPatilGenSpark/multi-agent-vedanti.git`
